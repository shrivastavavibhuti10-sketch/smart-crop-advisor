🌾 Smart Crop Advisory System

An AI-powered crop recommendation and intelligent advisory system designed to provide data-driven, explainable agricultural insights using Machine Learning and Generative AI.

🚀 Features

- 🌱 Crop Recommendation using Machine Learning
- 🤖 AI-powered Agricultural Advisory using a local LLM
- 📚 RAG-based Knowledge Retrieval with FAISS
- 🔎 Semantic Search using Sentence Transformers
- 📊 Explainable AI using SHAP
- 🌐 Hindi & English Support
- 🔒 Offline/Local AI Processing — no API key required
- 💻 Interactive Streamlit interface

🛠️ Technologies Used

Python • Scikit-learn • Pandas • NumPy • FAISS • Sentence Transformers • SHAP • Ollama • LLMs • RAG • Streamlit

🧠 AI Architecture

User Input → ML Crop Prediction → Knowledge Retrieval → FAISS → RAG → Local LLM → AI Advisory

🎯 Objective

To combine Machine Learning, Explainable AI, and Generative AI to create an accessible agricultural assistant that helps users make more informed crop-related decisions.
